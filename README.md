# Medicare Inpatient Hospital Data Analysis

## Project Overview

This project examines inpatient hospital utilization,
hospital charges, and Medicare payments using publicly
available data from the Centers for Medicare & Medicaid
Services (CMS).

The purpose is to identify patterns and variations in
hospital utilization and payment across hospitals and
Medicare Severity Diagnosis Related Groups (MS-DRGs).

## Research Questions

1. Which hospitals report the highest inpatient discharge volumes?
2. Which diagnosis groups have the highest average charges?
3. How do average hospital charges compare with average Medicare payments?
4. How do hospital utilization and payment measures vary geographically?
5. What data quality issues can be identified?
